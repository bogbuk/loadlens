# Per-tab контролы + сворачивание настроек в попапе — дизайн

Date: 2026-06-25
Status: approved

## Контекст

Три связанные правки по управлению LoadLens-расширением:

1. В попапе блок настроек идёт сверху, над аккаунтом — перестроить: аккаунт первым, настройки свернуть под него.
2. Авто-пилот таба DAT (авто-рефреш выдачи) сейчас глобальный (`chrome.storage.local.ll_autorefresh.on`) — включил в одной вкладке, включилось во всех. Нужно управление **отдельно по вкладкам**.
3. Нужна возможность **отключать наши подсказки** (построчные бейджи + плавающая панель) — отдельно по вкладкам.

## Ключевая механика: per-tab состояние через `sessionStorage`

`chrome.storage.local` общий для всех вкладок, поэтому per-tab флаги хранятся в `sessionStorage`
(привязан к вкладке+origin, **переживает `location.reload()`** — критично для reload-фолбэка
авто-пилота). Плюс: не нужно плодить `tabId`-ключи и слушать `chrome.tabs`.

Per-tab ключи:
- `ll_tab_autorefresh` = `"1"`/`"0"` — авто-пилот этой вкладки. Дефолт — выкл.
- `ll_tab_hints_off` = `"1"` когда подсказки скрыты. Дефолт — подсказки видны.

Существующий `sessionStorage.ll_autopilot_reload` (маркер reload-флоу) остаётся как есть.

## 1. Popup — настройки под аккаунт (`popup.html` + `popup.js`)

- Порядок блоков в `popup.html`: `#account` первым, затем `#settings`, далее `#fleet`, `#telegram`.
- Блок настроек оборачивается в нативный `<details>` (`<summary>⚙ Настройки</summary>`),
  по умолчанию **свёрнут** (без атрибута `open`). Содержимое `renderSettings()` рендерится внутрь.
- Логику настроек не меняем — только перестановка DOM и обёртка.
- CSS: лёгкий стиль для `<summary>` (курсор, отступ) в духе существующих `h4`.

## 2. Авто-пилот — полностью per-tab (`content.js` + `popup.js`)

- `autoRefresh.on` больше **не** читается/пишется в `chrome.storage.local`. Источник —
  `sessionStorage.ll_tab_autorefresh` (`"1"` → on), дефолт выкл. `autoRefresh.intervalMs`
  по-прежнему берётся из глобального `ll_autorefresh.intervalMs` (параметр, не вкл/выкл).
- Чекбокс «Авто-рефреш» в шапке панели (`#ll-ar`) переключает `autoRefresh.on`, пишет
  `sessionStorage.ll_tab_autorefresh` и вызывает `scheduleAuto()` напрямую (без записи в global).
- В попапе **убирается** строка-чекбокс «Авто-рефреш выдачи» (`#s-ar-on`). Интервал (`#s-ar-int`)
  и сортировка остаются — это глобальные параметры. `save()` пишет `ll_autorefresh: { intervalMs }`
  (без `on`).
- `onChanged`-листенер: для `ll_autorefresh` обновляет только `autoRefresh.intervalMs` и зовёт
  `scheduleAuto()`; `on` не трогает.
- Boot: `autoRefresh = { on: sessionStorage.ll_tab_autorefresh === "1", intervalMs: <из global или 60000> }`.
- Reload-фолбэк (`scheduleAuto` → `location.reload()`) продолжает работать: per-tab флаг переживает reload.

## 3. Отключение подсказок — per-tab (`content.js`)

- Новый флаг `hintsOff` ← `sessionStorage.ll_tab_hints_off === "1"` (дефолт false).
- В шапке панели — новая кнопка-тумблер «🙈 Подсказки» (рядом с «–»).
- `render()`: если `hintsOff` → `clearBadges()` + **пропуск** инъекции `anchor`/`badgeRow`, и панель
  сворачивается в FAB (как `panelCollapsed`). FAB-клик (или повторный тумблер) → `hintsOff=false`,
  `sessionStorage` обновляется, полный рендер.
- Авто-пилот при `hintsOff` **продолжает крутиться**: расчёт greens + `LLALERT.push` и таймер
  считаются до early-return панели и от неё не зависят.
- Существующая кнопка «–» (`panelCollapsed`) остаётся как лёгкое сессионное сворачивание панели
  (бейджи остаются). Это сознательно два разных контрола: «–» = свернуть панель в этой сессии;
  «🙈 Подсказки» = per-tab скрытие бейджей + панели, переживает reload.

## Вне scope

Скоринг, бэкенд, Telegram-алерты, `vendor/`/`shared/`, DOM-селекторы DAT. Только UI-слой расширения.

## Тестирование

- `popup.js` логики — без изменений поведения; ручная проверка раскладки.
- `content.js` — добавить юнит-покрытие для чистых хелперов, если выделятся (напр. чтение per-tab
  флага). Основное — ручная проверка в живой сессии DAT: (а) две вкладки, авто-пилот независим;
  (б) тумблер подсказок прячет бейджи+панель и переживает reload; (в) попап-настройки свёрнуты под аккаунт.
