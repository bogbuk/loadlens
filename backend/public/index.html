LoadLens

Crowd-база грузов и API для расширения. Сервис работает.

API /api/v1

  • POST /loads — ingest грузов (расширение)
  • GET /lanes/:origin/:dest?equipment= — медиана RPM по lane
  • GET /markets/:market/strength — сила рынка
  • GET /geo/distance?from=&to= — дорожные мили
  • GET /rates — цена дизеля (EIA)
  • POST /auth/register|login|refresh, GET /auth/me

Health: /healthz
