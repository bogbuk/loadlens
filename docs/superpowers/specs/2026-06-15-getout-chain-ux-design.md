# Get-out цепочки — UX раскрытия плеч

Date: 2026-06-15
Status: approved (design)

## Проблема

Get-out цепочка (hero-фича LoadLens) сейчас рендерится в плавающей панели как
тупиковая карточка: строка-маршрут рынков + одна мета-строка
(`$2.10/mi · net $1500 · 1200mi · HOS ✓`). Диспетчер видит итог, но:

1. **Тупик** — карточка некликабельна; нельзя ни забукать первое плечо, ни прыгнуть к грузу в выдаче DAT.
2. **Нет плеч** — виден маршрут рынков, но не *грузы*: брокер, ставка по каждому плечу, deadhead, HOS.
3. **Нет «почему»** — не сказано, что финиш-рынок сильный, а старт «тихий».
4. **Нет горизонта** — `net $1500` за сколько дней? Без времени RPM несравним.
5. **Нет доверия** — onward-плечи из крауд-базы (могут быть «вчерашние»), но это не помечено как прогноз.

## Главный сценарий (job-to-be-done)

**«Раскрыть и понять»**: диспетчер кликает цепочку → видит плечи (конкретные грузы,
брокеры, ставки, deadhead, HOS по каждому) → сам доверяет и решает. Не booking через
нас, не сохранение плана — именно понимание и доверие.

## Решение

Раскрываемая цепочка (аккордеон в панели) с **честной разметкой плеч** по источнику данных.

### 1. Сводка цепочки (шапка раскрытой карточки)

`$/mi · net $ · ~N дней · $/день · сила финиш-рынка`

- **Горизонт `~N дней`** и **`$/день`** отвечают на «net за сколько». Считаются из
  суммарного времени работы цепочки: `(Σ driveMin + Σ idleMin + Σ load/unload) / рабочий_день`.
- Сила финиша — `marketStrength(finalMarket)` (уже есть), показываем как `▰▰▰▰▱` + словом.

### 2. Аккордеон на месте

- Клик по свёрнутой цепочке раскрывает плечи прямо в списке (остальные сдвигаются вниз),
  повторный клик сворачивает. Одновременно раскрыта одна цепочка.
- Свёрнутый вид: маршрут + `$/mi · net · ~N дней · $/день · HOS`-бейдж + индикатор `▸/▾`.

### 3. Плечо 1 — «живое» («● СЕЙЧАС В ВЫДАЧЕ»)

Зелёный ярлык, кликабельное. Источник — видимый груз DAT (из текущей выдачи).

- **Клик = прокрутить выдачу DAT к строке груза + мигающая подсветка** (через
  `resultId` → DOM-строка, как в `dat.adapter.anchor`). Диспетчер дальше жмёт родной
  Book/Call в UI DAT. ToS-безопасно — мы не инициируем запросов к DAT.
- Строка плеча: `origin → dest · $rate · Nmi +DHdh · $X.XX/mi · HOS-бейдж`.
- Чипы (данные уже в распарсенном `Load`):
  - **Репутация брокера (crowd)** — good/mixed/bad/thin по MC из `backend/brokers`.
  - **Дата pickup** — `availability.earliest` («pickup сегодня / 12 июн»).
  - **Груз** — `weight` + `lengthFt` («42klb · 48ft»).
  - **Флаги сделки** — `isNegotiable` (торг), `isFactorable` (факторинг), `bookNow` (Book Now).

### 4. Плечи 2–3 — «прогноз» («◔ ПРОГНОЗ ПО РЫНКУ · видели N дней назад»)

Приглушённые (opacity ~0.7), **некликабельны** (конкретного груза ещё нет).
Источник — крауд-база (`GET /loads?origin=<destMarket>`).

- Строка: `origin → dest · $X.XX/mi медиана lane · ~N грузов/нед · HOS-бейдж`.
- Метка свежести «видели N дней назад» — честно показывает, что это память рынка,
  а не активный груз.
- На последнем плече — сила рынка назначения (`▰▰▰▱▱`).

## За рамками (YAGNI)

- Booking/звонок через нас (контакты — PII, и так в строке DAT).
- Сохранение цепочки как плана активного водителя.
- «Детальный экран» с back-кнопкой — выбран аккордеон на месте.
- Отдельная иконка «i» для второго уровня — клик плеча 1 = только прокрутка к строке.

## Затрагиваемые компоненты

| Файл | Изменение |
|---|---|
| `shared/planner.js` | `finalize` дополнительно отдаёт суммарное drive-время плеч (`totalDriveMin`), чтобы UI считал горизонт `~N дней` и `$/день`. Чистая функция, без сети/DOM. Затем `npm run sync:shared`. |
| `extension/content.js` | `chainRow` → раскрываемый рендер (свёрнутый/раскрытый + аккордеон-стейт); рендер плеч с разметкой live/прогноз и чипами; обработчик клика плеча 1 → scroll+highlight. |
| `extension/adapters/dat.adapter.js` | (возможно) хелпер `scrollToRow(resultId)` + подсветка, переиспользуя матчинг `anchor`. |
| Панель CSS (в `content.js`) | стили плеч, чипов, ярлыков live/прогноз, аккордеона. |

Backend без изменений — все нужные данные уже приходят: `availability`, `weight`,
`lengthFt`, `isNegotiable`/`isFactorable`/`bookNow`, crowd-репутация (`brokers`),
медиана lane (`lanes`), плотность/сила рынка (`markets`).

## Проверка

- `npm test` (shared + extension) зелёный, включая обновлённый `planner` (новое поле
  `totalDriveMin` в выводе `finalize`).
- `npm run sync:shared` после правки `shared/planner.js`.
- Ручная проверка в `chrome://extensions` поверх живой сессии DAT: раскрытие/сворачивание,
  клик плеча 1 → прокрутка к строке, корректные ярлыки live/прогноз.
